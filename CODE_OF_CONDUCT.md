# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about the work, not the person.
Harassment, insults and personal attacks aren't tolerated in issues, discussions or pull requests.

Report problems privately to the maintainer ([dskiba](https://github.com/dskiba)). Reports are kept
confidential. Maintainers may remove content and block anyone who breaks these rules.
