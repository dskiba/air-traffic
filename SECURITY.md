# Security

Air Traffic sees every link you open, so security reports matter.

**Report privately** through [GitHub's private vulnerability reporting](https://github.com/dskiba/air-traffic/security/advisories/new).
Please don't open a public issue. You'll get a reply within a week.

In scope: anything that sends a link somewhere you didn't choose (for example a rule bypass, or a
private window that isn't private), leaks links, or runs code from a crafted link or config.

Only the latest release gets fixes.
